# quiz-safe-mode

Part of dark-mode; see [dark-mode.md](dark-mode.md) §7 "Quiz pages". The default is **Leave untouched**: on quiz-taking routes (classic `/courses/:id/quizzes/:id/take`, New Quizzes LTI launches, and Respondus/lockdown pages), boot sets no b²c attributes at all, so no b²c CSS or widget applies. The popup shows "b²c is paused on quiz pages" on those tabs.
