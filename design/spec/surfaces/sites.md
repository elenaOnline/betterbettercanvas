# sites

Settings → **Sites**: the list of Canvas addresses b²c runs on. `*.instructure.com` is first, labelled "Built in", and can't be removed. Custom domains added in first run or here follow it. "Add site…" takes a URL, normalises it to an origin, and asks the browser for that host's permission (Chrome's own prompt). If permission is denied, the row says "Permission not granted · Try again". Each row has Remove. **"Not allowed" state** (users read silent permission failures as "my settings reset"): when b²c is installed but the current Canvas tab's host isn't granted, the toolbar icon shows a small dot, and the popup opens to one card: "**Allow b²c on canvas.example.edu**" [Allow] with the line "Your settings are safe; b²c just can't reach this site yet." The same card appears at the top of Settings → Sites. Instructure-hosted schools (`*.instructure.com`) work out of the box.
