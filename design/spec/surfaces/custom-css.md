# custom-css

A code field (monospace, 8 rows, resizable) in Appearance → Advanced. It applies on blur and on ⌘S, not on every keystroke, gated under `html[data-b2c-custom-css]` as a `<style>` that boot inserts from the mirror (pre-paint). A syntax error shows inline, with the line number, from the CSSOM parse. Help text: "Advanced. Applies to every Canvas page."
